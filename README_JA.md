# edge-secure-token (日本語ドキュメント)

Edge、Cloudflare Workers、Node.js 向けのゼロ依存・タイミング攻撃耐性付き WebCrypto JWT ライブラリ。フィールドレベルクレーム暗号化を標準搭載しています。

---

## 主な特長

1. **外部依存ゼロ**: WebCrypto の標準 API のみで動作。
2. **定時間比較によるタイミング攻撃防御**: HMAC 照合等でバイト単位の定時間比較を適用。
3. **`alg: none` 攻撃の構造的排除**: 署名なしトークンを一切拒絶。
4. **フィールドレベル暗号化 (FLE)**: トークン内の特定の機密クレームのみを AES-GCM で部分暗号化。
